# Sivaprakasam_Schweinzger_CA_TTS_Code
This repository contains scripts used to process and represent data in our work titled "Differentiating the Physiological Signatures of Cochlear Synaptopathy and Inner Hair Cell Damage in a Chinchilla Model"

Raw data files may be found in the corresponding Zenodo [dataset](https://doi.org/10.5281/zenodo.20025720).
